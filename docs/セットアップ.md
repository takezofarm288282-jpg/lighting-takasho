# セットアップ手順

やることは2つだけです。

1. GitHub Pages で公開する
2. Googleスプレッドシートに記録できるようにする（任意）

---

## 1. GitHub Pages で公開する

1. GitHub でこのリポジトリ（`lighting-takasho`）を開く
2. 上のタブの **Settings** → 左メニューの **Pages**
3. **Source** を **GitHub Actions** に変更して保存
4. コードを push すると自動でビルドされ、数分後に公開される

公開URL:
```
https://takezofarm288282-jpg.github.io/lighting-takasho/
```

うまくいかないときは **Actions** タブを開くと、赤いバツ印のところに理由が出ます。

---

## 2. Googleスプレッドシートに記録する（任意）

この設定をしない場合でも、商品の絞り込み・見積・PDFは普通に動きます。
どんな商品で見積が作られたかの記録が残らないだけです。

### ① スプレッドシートを作る

1. Googleドライブで新しいスプレッドシートを作る
2. 名前は「ガーデンライト 見積記録」など分かりやすいものに

### ② スクリプトを貼り付ける

1. スプレッドシートのメニュー **拡張機能** → **Apps Script**
2. 最初から入っているコードを全部消す
3. このリポジトリの `docs/gas-code.gs` の中身を全部コピーして貼り付ける
4. 上の方の `CONFIG` を確認する

```js
const CONFIG = {
  ADMIN_PASSWORD: 'takasho2024admin',   // 管理画面のパスワード
  NOTIFY_EMAIL: 'izumo@takezofarm.co.jp', // 見積の通知先メール
  SEND_MAIL: true,                       // メール通知が不要なら false
};
```

5. 保存（フロッピーのアイコン）

### ③ ウェブアプリとして公開する

1. 右上の **デプロイ** → **新しいデプロイ**
2. 歯車マーク → **ウェブアプリ** を選ぶ
3. 設定を次のようにする
   - 説明：なんでもよい（例：v1）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. **デプロイ** を押す
5. 初回は「承認」を求められるので、自分のGoogleアカウントで許可する
   （「このアプリは確認されていません」と出たら、**詳細** → **安全でないページに移動** を押す）
6. 表示される **ウェブアプリのURL** をコピーする
   （`https://script.google.com/macros/s/……/exec` という形）

### ④ アプリにURLを貼る

`src/config.ts` を開いて、コピーしたURLを貼り付けます。

```ts
export const GAS_URL = "https://script.google.com/macros/s/……/exec";
```

保存して push すれば完了です。

> スクリプトを修正したときは、**デプロイ** → **デプロイを管理** → 鉛筆マーク →
> バージョンを「新バージョン」にして更新してください。URLは変わりません。

## 3. ホームページ（WordPress）の埋め込みを差し替える

`https://takezofarm.co.jp/lighting/` のページを編集し、
埋め込んでいる iframe のURLを、古い `https://app.takezofarm.co.jp/` から
新しい公開URLに変更します。

```html
<iframe src="https://takezofarm288282-jpg.github.io/lighting-takasho/"
        style="width:100%;height:900px;border:0;" loading="lazy"></iframe>
```

## 困ったとき

| 症状 | 見るところ |
|---|---|
| ページが真っ白 | GitHubの **Actions** タブでビルドが失敗していないか |
| 記録が残らない | `src/config.ts` の `GAS_URL` が空でないか／GASのデプロイが「全員」か |
| メールが来ない | GASの `SEND_MAIL` が `true` か／`NOTIFY_EMAIL` が正しいか |
| 管理画面に入れない | GASの `ADMIN_PASSWORD` と入力が一致しているか |
